# Elaina Birthday Fan Website

An airy, animated birthday tribute to Elaina from *The Journey of Elaina*, built with React, Vite, Tailwind CSS, and Motion.

## Run locally

```sh
npm install
npm run dev
```

The dev server uses port 3000. Run `npm run lint` for the TypeScript check and `npm run build` for a production build.

## Replace the illustration placeholders

The six transparent PNGs are stored as `public/assets/elaina-1.png` through `public/assets/elaina-6.png`; their section mapping is in `src/data/elainaAssets.ts`. Missing files automatically show labeled placeholders.
